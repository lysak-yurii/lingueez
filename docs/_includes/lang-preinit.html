{%- comment -%} First-visit language routing, before paint. GitHub Pages serves static files, so there is no server-side Accept-Language negotiation to hook into: the apex has to be English for everyone, and the visitor is moved from there. That makes this the one piece of the site that can send someone somewhere they did not ask to go, so the rules are narrow: * Only the unprefixed English copy ever redirects. Every other URL is already an explicit request for that language — a shared link, a search result, a pick from the menu — and is left alone. * An explicit choice always beats the browser list, and is remembered for a year. Reading a prefixed page counts as a choice. * ?lang=xx is the escape hatch, and the picker's English link carries it, so "switch to English" cannot be undone by this script on the way there. The parameter is stripped from the address bar once it has been recorded. * location.replace, not assign: the redirect leaves no history entry, so Back goes where the visitor came from instead of bouncing off the apex again. Search engines are served by the hreflang set in head.html, which points at the real URLs; Googlebot renders with an en-US language list and so falls through this without redirecting. Skipped on pages with no `base` (404, legal) — they have no translated twins to route to. {%- endcomment -%} {%- if page.base -%} {%- endif -%}
