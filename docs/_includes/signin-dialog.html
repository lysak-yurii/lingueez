A native rather than a hand-rolled overlay: showModal() gives the focus trap, the Escape key, the inert background and the ::backdrop for free, and all four are easy to get wrong. The Log in control stays a real link to the web app, so it still works with no JavaScript — signin.js intercepts the click and opens this instead. {%- endcomment -%}
